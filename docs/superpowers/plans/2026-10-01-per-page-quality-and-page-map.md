# Per-Page Quality and Page Map — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-09-24-index.md` (cross-phase contracts) and the spec below first; Task 0 amends the index — every later task relies on the amended contracts.

**Goal:** Every converted PDF carries one `<!-- page: N -->` per page by construction (MinerU via its own per-page render plan, MarkItDown via per-page extraction, Docling unchanged); page-map completeness, page alignment and per-page text quality (T-001 broken text layers) become part of quality with a new `warn` level; broken pages are repaired per page by OCR and spliced back; existing outputs are re-assessed and can be reconverted in one click; a real-sample gate and a sync-accuracy e2e keep it honest.

**Spec:** `docs/superpowers/specs/2026-10-01-per-page-quality-and-page-map.md` (Traditional Chinese; §3 has the spike numbers every threshold below comes from). Ticket: `docs/tickets/T-001-head-first-android-cover-garbled.md`.

**Architecture:** Runners emit per-page markdown (MinerU: `docvortex` render plan rendered page by page, self-checked byte-for-byte against `markdown.md`, public single-page render as fallback). The host gains `pagemap.py` (sections, coverage, alignment spot check, splice) and per-page signals in `quality.py`; `pipeline.py` assesses each segment (coverage + spot check), then the merged document (coverage, alignment, flagged pages), repairs flagged pages through `repair.py` (Docling pypdfium + FULL_PAGE OCR, then MinerU `ocr_mode="ocr"`), and maps the result to `ok | warn | low`. `reassess.py` grades existing outputs at startup/rescan; the API exposes `flags`/`page_summary` and `POST /documents/reconvert`; the web shows badges, banners, per-page warnings and a 「跳至頁」 control.

**Tech Stack:** Python 3.10 host (PyMuPDF, FastAPI), engine envs (MinerU 4.0.7 + docvortex 0.4.25, Docling 2.130, MarkItDown 0.1.8), React/TypeScript web, Vitest, Playwright, pdfjs-dist (Node, e2e).

### Task 1: `pagemap.py` — sections, coverage, alignment spot check, splice

**Files:**
- Create: `src/aidoc/pagemap.py`, `tests/unit/test_pagemap.py`

**Interfaces:**
- `MARKER = re.compile(r"<!-- page: (\d+) -->")`
- `split_pages(md: str) -> tuple[str, dict[int, str]]` — (text before the first marker, `{page: section}`); a page that appears twice gets its sections concatenated.
- `page_map(md: str, expected: int | None, method: str | None) -> dict | None` — `None` when `expected` is None; else `{expected, found, coverage (4 dp), missing: [≤ 200 pages], missing_truncated?: true, method}`; markers outside `1..expected` are ignored.
- `squash(s: str) -> str` — NFKC, drop U+00AD and `-\n`, lower-case, keep `str.isalnum()` chars.
- `spot_check(md: str, pdf: Path, *, sample: int = 30, exclude: Iterable[int] = (), win: int = 24, k: int = 3, min_chars: int = 120) -> dict` — spec §7 v3 algorithm, deterministic; returns `{sampled, decidable, aligned, ratio (4 dp or None), misplaced: [≤ 10], excluded_pages}`.
- `splice_pages(md: str, replacements: dict[int, str]) -> str` — replaces the text between `<!-- page: N -->` and the next marker; the marker line and everything else are byte-identical; unknown pages raise `KeyError`.

### Task 3: Per-page quality model in `quality.py`

**Files:**
- Modify: `src/aidoc/quality.py`, `tests/unit/test_quality.py`

**Interfaces:**
- Constants listed in Global Constraints; `COMMON_WORDS` = the word list of spec §8.1; `SHIFT = 29`.
- `page_signals(text: str) -> dict` → `{"chars": int (non-space after strip_markup), "fffd_between": int, "garbage": float (4 dp), "shift_hits": int}`; `shift_hits` = number of printable-ASCII tokens (`[\x21-\x7e]{1,12}`, U+FFFD treated as a separator) that become a `COMMON_WORDS` entry when every char code is shifted by +29 (codes that would pass 0x7e invalidate the token).
- `flag_page(sig: dict, broken_font: bool) -> list[str]` → `["broken_text_layer"]` when `broken_font` and (`fffd_between ≥ 1` or (`chars ≥ 50` and `garbage > 0.05`) or `shift_hits ≥ 3`); else `["garbage"]` when `chars ≥ 50` and `garbage > 0.05`; else `[]`.
- `flag_pages(md: str, broken_font_pages: Iterable[int]) -> list[dict]` → `[{page, reasons, metrics}]` for flagged pages (uses `pagemap.split_pages`); for markdown without markers returns `[]` (the document-level garbage rule covers it).
- `page_signals` counts `fffd_between` with look-arounds (`(?<=\S)\N{REPLACEMENT CHARACTER}(?=\S)`), so consecutive replacement characters each count once.
- `assess(markdown, probe, pages, *, pdf: Path | None = None, page_map_method: str | None = None, quick: bool = False, flagged_before: int | None = None, repaired: list[dict] | None = None, align_sample: int | None = None) -> QualityResult` — `repaired` = the pre-repair page entries (`{page, reasons, metrics}`) of pages that were successfully repaired, each with `repaired_by` added; they are copied into `pages` verbatim.
  - legacy behaviour (three reasons, score) unchanged when `probe.kind != "pdf"` or `pages is None`, except `page_check = PAGE_CHECK_VERSION` is set for every result.
  - PDF: `page_map = pagemap.page_map(markdown, pages, page_map_method)`; `missing` pages become page entries `page_map_missing`; `coverage < COVERAGE_MIN` → reason `page_map_incomplete`.
  - Alignment when `pdf` is given: `spot_check(markdown, pdf, sample=align_sample or (10 if quick else 30), exclude=probe.broken_font_pages)` stored under `page_map["alignment"]`; `decidable ≥ 5 and ratio < 0.90` → `page_map_misaligned`.
  - Flagged pages: `flag_pages(markdown, probe.broken_font_pages)` (still-broken pages, no `repaired_by`) + `repaired` entries + `page_map_missing` entries, sorted by page; `pages_flagged = flagged_before if flagged_before is not None else len(flagged)`; when **not** `quick` and `pages_flagged > FLAGGED_MAX_RATIO × max(1, pages − len(blank_pages))` → reason `pages_flagged`.
  - Level: any reason → `low`; else any page entry without `repaired_by` → `warn`; else `ok`. Score = `base × coverage × (1 − unrepaired / effective_pages)` (3 dp; coverage 1 for non-PDF).
