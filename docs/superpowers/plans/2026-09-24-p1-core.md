# P1 — Core CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-09-24-index.md` first — its §0 constraints, §3 types, §4 schema, §5 runner protocol and §6 fake scenario are binding.

**Goal:** A working `aidoc convert` / `aidoc batch` / `aidoc setup` CLI that probes a file, routes it to MarkItDown / Docling / MinerU (each in its own uv env), checks quality, normalises output, writes `out/<stem>/` atomically and records everything in SQLite.

**Architecture:** Light main package `src/aidoc` (no torch) talks to engine runners over the stdin/stderr JSON protocol; each engine is a subprocess in `envs/<engine>/.venv`. Pure modules (`probe`, `router`, `quality`, `normalize`, `names`, `fsops`) are unit-tested without GPU; the pipeline is tested with the fake engine; real engines are covered by `@pytest.mark.slow` integration tests.

**Tech Stack:** Python ≥ 3.10, uv, PyMuPDF, psutil, tiktoken, tomli/tomli-w, pytest; engine envs: markitdown 0.1.8, docling 2.x (`[easyocr]`), mineru 4.0.x (`[torch]`), torch cu128.

**Spec:** `docs/superpowers/specs/2026-09-24-ai-friendly-doc-design.md` §1–§5, §8.1, §8.2 (kinds only), §8.6, §8.8 (timeouts), §9, §10 (unit + integration), §13.

See index §0. Additionally for P1:
- Every commit uses the trailer lines from index §0.

- Unit tests must pass with `uv run pytest -m "not slow"` on a machine **without** engine envs installed.

## Review Focus

Inputs the spec implies but does not spell out; each has a pinned test in the owning task:
1. Source named with a Windows reserved stem or trailing dot/space (`CON.pdf`, `report..pdf`, `a<b>.docx`) must still produce a valid output dir — test in Task 4.
2. A PDF with 0 pages, or all pages blank, must not divide by zero in quality and must end as `failed(input)`/`low` rather than crash — tests in Task 7 and Task 9.
3. Non-ASCII (Traditional Chinese) and space-containing paths for source, workdir and output must survive the runner protocol — test in Task 12 (host) and Task 18 (pipeline).
4. Two sources with the same stem but different content in one batch (`report.pdf` + `report.docx`) must get distinct output dirs and both appear in the manifest — test in Task 17 and Task 20.
5. An unsupported extension (`.exe`) in a batch must yield `failed(input: unsupported_type)` and the batch must continue — test in Task 8 (router) and Task 20 (batch).

```python
# src/aidoc/paths.py
from __future__ import annotations
import os, sys
from pathlib import Path

_PKG_ROOT = Path(__file__).resolve().parent            # src/aidoc

def project_root() -> Path:
    """AIDOC_ROOT env, else the checkout that contains this package (src/aidoc -> repo)."""
    env = os.environ.get("AIDOC_ROOT")
    if env:
        return Path(env).resolve()
    return _PKG_ROOT.parent.parent

def data_dir() -> Path:
    env = os.environ.get("AIDOC_DATA")
    return Path(env).resolve() if env else project_root() / "data"

def envs_dir() -> Path:
    return project_root() / "envs"

def models_dir() -> Path:
    return data_dir() / "models"

def venv_python(engine: str) -> Path:
    venv = envs_dir() / engine / ".venv"
    if sys.platform == "win32":
        return venv / "Scripts" / "python.exe"
    return venv / "bin" / "python"

def ready_marker(engine: str) -> Path:
    return envs_dir() / engine / ".ready"

def runner_dir() -> Path:
    return _PKG_ROOT / "engines" / "runner"

def runner_script(engine: str) -> Path:
    return runner_dir() / f"{engine}_runner.py"
```

```python
# src/aidoc/fsops.py
from __future__ import annotations
import errno, json, os, shutil, stat, time
from pathlib import Path
from typing import Callable, Iterable, TypeVar
T = TypeVar("T")
_RETRY_ERRNOS = {errno.EACCES, errno.EBUSY, errno.EPERM}

class FsBusyError(OSError):
    """Rename/delete kept failing because another process holds a handle."""

def retry_fs(fn: Callable[[], T], *, attempts: int = 5, base_delay: float = 0.2) -> T:
    last: Exception | None = None
    for i in range(attempts):
        try:
            return fn()
        except (PermissionError, OSError) as e:
            if isinstance(e, PermissionError) or getattr(e, "errno", None) in _RETRY_ERRNOS:
                last = e
                if i < attempts - 1:
                    time.sleep(base_delay * (2 ** i))
                continue
            raise
    raise FsBusyError(errno.EBUSY, f"filesystem busy after {attempts} attempts: {last}")

def _tmp_name(path: Path) -> Path:
    return path.with_name(f".{path.name}.tmp")

def atomic_write_text(path: Path, text: str, encoding: str = "utf-8") -> None:
    path = Path(path); path.parent.mkdir(parents=True, exist_ok=True)
    tmp = _tmp_name(path)
    with open(tmp, "w", encoding=encoding, newline="\n") as f:
        f.write(text); f.flush(); os.fsync(f.fileno())
    retry_fs(lambda: os.replace(tmp, path))

def atomic_write_json(path: Path, obj) -> None:
    atomic_write_text(path, json.dumps(obj, ensure_ascii=False, indent=2) + "\n")

def atomic_write_lines(path: Path, lines: Iterable[str]) -> None:
    atomic_write_text(path, "".join(l.rstrip("\n") + "\n" for l in lines))

def _on_rm_error(func, p, exc_info):
    os.chmod(p, stat.S_IWRITE); func(p)

def remove_tree(path: Path) -> None:
    path = Path(path)
    if not path.exists():
        return
    retry_fs(lambda: shutil.rmtree(path, onerror=_on_rm_error))

def replace_dir_three_step(tmp_dir: Path, final_dir: Path, trash_dir: Path) -> None:
    """Spec §8.6. Any failure raises FsBusyError; final_dir is never half-replaced."""
    tmp_dir, final_dir, trash_dir = Path(tmp_dir), Path(final_dir), Path(trash_dir)
    final_dir.parent.mkdir(parents=True, exist_ok=True)
    if final_dir.exists():
        trash_dir.parent.mkdir(parents=True, exist_ok=True)
        if trash_dir.exists():
            remove_tree(trash_dir)
        retry_fs(lambda: os.replace(final_dir, trash_dir))          # step 1
    retry_fs(lambda: os.replace(tmp_dir, final_dir))                # step 2
    try:
        remove_tree(trash_dir)                                      # step 3 (recovery cleans if this fails)
    except FsBusyError:
        pass
```

```python
# src/aidoc/engines/runner/_proto.py
"""Shared by all runners. STDLIB ONLY. Never import aidoc here."""
from __future__ import annotations
import json, sys, traceback
from typing import Callable

def _emit(prefix: str, obj: dict) -> None:
    sys.stderr.write(f"{prefix} {json.dumps(obj, ensure_ascii=False)}\n"); sys.stderr.flush()

def ready() -> None: _emit("AIDOC_READY", {})
def progress(page: int, total: int) -> None: _emit("AIDOC_PROGRESS", {"page": page, "total": total})
def log(msg: str) -> None:
    sys.stderr.write(msg.rstrip("\n") + "\n"); sys.stderr.flush()

class RunnerError(Exception):
    def __init__(self, kind: str, message: str):
        super().__init__(message); self.kind = kind

def serve(handle: Callable[[dict], dict]) -> None:
    """Loop: each stdin line = path of request.json. handle(req) returns the result dict."""
    ready()
    for line in sys.stdin:
        req_path = line.strip()
        if not req_path:
            continue
        try:
            with open(req_path, encoding="utf-8") as f:
                req = json.load(f)
            result = handle(req)
            res_path = req_path[: -len("request.json")] + "result.json" if req_path.endswith("request.json") else req_path + ".result.json"
            with open(res_path, "w", encoding="utf-8") as f:
                json.dump(result, f, ensure_ascii=False)
            _emit("AIDOC_DONE", {"request": req_path, "result": res_path})
        except RunnerError as e:
            _emit("AIDOC_ERROR", {"request": req_path, "kind": e.kind, "message": str(e)})
        except Exception as e:  # noqa
            log(traceback.format_exc())
            _emit("AIDOC_ERROR", {"request": req_path, "kind": "engine", "message": f"{type(e).__name__}: {e}"})
```

```python
def _attempt_no(sc, source, engine, pages):
    logp = sc.get("call_log")
    key = {"source": os.path.basename(source), "engine": engine, "pages": pages}
    n = 1
    if logp and Path(logp).exists():
        for line in Path(logp).read_text(encoding="utf-8").splitlines():
            if json.loads(line) == key:
                n += 1
    if logp:
        with open(logp, "a", encoding="utf-8") as f:
            f.write(json.dumps(key) + "\n")
    return n

def _behavior(sc, req, attempt):
    src = os.path.basename(req["src"]); engine = req["engine_opts"].get("fake_engine", "")
    seg_idx = req.get("segment_idx", 0)
    for rule in sc.get("rules", []):
        m = rule.get("match", {})
        if "source_glob" in m and not fnmatch.fnmatch(src, m["source_glob"]): continue
        if "engine" in m and m["engine"] != engine: continue
        if "attempt" in m and m["attempt"] != attempt: continue
        if "segment_idx" in m and m["segment_idx"] != seg_idx: continue
        return rule["behavior"]
    return sc.get("default", "ok")

def _write_ok(req, sc, with_pages=True):
    out = Path(req["out_dir"]); (out / "images").mkdir(parents=True, exist_ok=True)
    pages = req.get("pages")
```

```python
class RunnerHost:
    def __init__(self, python, script, env_extra, startup_timeout_s=900.0):
        self.python, self.script, self.env_extra, self.startup_timeout_s = Path(python), Path(script), dict(env_extra), startup_timeout_s
        self.proc = None; self._lines: queue.Queue[str | None] = queue.Queue(); self._tail = collections.deque(maxlen=200)
        self.ready = False; self.pid = None
    def start(self, cwd):
        env = {**os.environ, **runner_env(paths.data_dir()), **self.env_extra}
        self.proc = subprocess.Popen([str(self.python), str(self.script)], cwd=str(cwd), env=env, stdin=subprocess.PIPE,
                                     stdout=subprocess.DEVNULL, stderr=subprocess.PIPE, **procs.popen_kwargs())
        self.pid = self.proc.pid
        threading.Thread(target=self._pump, daemon=True).start()
    def _pump(self):
        with io.TextIOWrapper(self.proc.stderr, encoding="utf-8", errors="replace") as f:
            for line in f: self._tail.append(line); self._lines.put(line)
        self._lines.put(None)
    def alive(self): return self.proc is not None and self.proc.poll() is None
    def run(self, request, workdir, timeout_s, on_progress):
        workdir.mkdir(parents=True, exist_ok=True)
        req_path = workdir / "request.json"; req_path.write_text(json.dumps(request, ensure_ascii=False), encoding="utf-8")
        self._wait_ready()                         # bounded by startup_timeout_s -> EngineError(transient, "startup timeout")
        self.proc.stdin.write((str(req_path) + "\n").encode("utf-8")); self.proc.stdin.flush()
        deadline = time.monotonic() + timeout_s
        while True:
            try: line = self._lines.get(timeout=0.25)
            except queue.Empty: line = ""
            if line is None or (line == "" and not self.alive()):
                self._raise_dead("runner exited")
            if time.monotonic() > deadline:
                self.close(); raise EngineError(ErrorKind.transient, f"timeout after {timeout_s:.0f}s")
            if not line: continue
            kind, payload = _parse(line)           # ("PROGRESS"|"DONE"|"ERROR"|"READY"|None, dict)
            if kind == "PROGRESS":
                on_progress(min(1.0, payload["page"] / max(1, payload["total"])), "")
            elif kind == "DONE":
                return json.loads(Path(payload["result"]).read_text(encoding="utf-8"))
            elif kind == "ERROR":
                raise EngineError(ErrorKind(payload["kind"]), payload["message"])
            elif kind is None:
                on_progress(-1.0, line.rstrip("\n"))   # log line, fraction -1 means "no progress info"
    def _raise_dead(self, why):
        tail = "".join(self._tail); oom = ("CUDA out of memory" in tail) or ("OutOfMemoryError" in tail)
        raise EngineError(ErrorKind.transient, f"{why} (code {self.proc.returncode}): {tail[-500:]}", oom=oom)
    def close(self):
        if self.proc is None: return
        try: self.proc.stdin.close()
        except OSError: pass
        try: self.proc.wait(timeout=3)
        except subprocess.TimeoutExpired: procs.kill_tree(self.proc.pid); self.proc.wait(timeout=10)
```

```python
# src/aidoc/engines/runner/markitdown_runner.py  (stdlib + markitdown + python-pptx only)
from __future__ import annotations
import re, sys, zipfile
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent))
import _proto
import xml.etree.ElementTree as ET

NS = {"w": "http://schemas.openxmlformats.org/wordprocessingml/2006/main",
      "a": "http://schemas.openxmlformats.org/drawingml/2006/main",
      "r": "http://schemas.openxmlformats.org/officeDocument/2006/relationships",
      "rel": "http://schemas.openxmlformats.org/package/2006/relationships"}
IMG_LINK = re.compile(r"!\[([^\]]*)\]\(([^)\s]+)\)")

def docx_media_in_order(path):
    with zipfile.ZipFile(path) as z:
        rels = ET.fromstring(z.read("word/_rels/document.xml.rels"))
        rid2target = {r.get("Id"): r.get("Target") for r in rels.findall("rel:Relationship", NS)}
        doc = ET.fromstring(z.read("word/document.xml"))
        out = []
        for blip in doc.iter(f"{{{NS['a']}}}blip"):
            rid = blip.get(f"{{{NS['r']}}}embed")
            target = rid2target.get(rid)
            if target:
                name = "word/" + target if not target.startswith("/") else target[1:]
                out.append((Path(target).name, z.read(name)))
        return out

def replace_nth_images(md, replacements):
    it = iter(replacements)
    def sub(m):
        try: return f"![{m.group(1)}]({next(it)})"
        except StopIteration: return m.group(0)
    return IMG_LINK.sub(sub, md)

def slide_markers_to_pages(md):
    return re.sub(r"<!-- Slide number: (\d+) -->", r"<!-- page: \1 -->", md)

def pptx_pictures_in_order(path):
    from pptx import Presentation
    from pptx.enum.shapes import MSO_SHAPE_TYPE
    out = []
    def walk(shapes):
        for sh in shapes:
            if sh.shape_type == MSO_SHAPE_TYPE.GROUP: walk(sh.shapes)
            elif sh.shape_type == MSO_SHAPE_TYPE.PICTURE: out.append((sh.image.ext, sh.image.blob))
    for slide in Presentation(path).slides: walk(slide.shapes)
    return out

def handle(req):
    from markitdown import MarkItDown
    src = Path(req["src"]); out = Path(req["out_dir"]); (out / "images").mkdir(parents=True, exist_ok=True)
    ext = src.suffix.lower()
    if ext in {".mp3", ".wav", ".m4a"} and not req["engine_opts"].get("allow_online_audio"):
        raise _proto.RunnerError("input", "audio_disabled")
    md = MarkItDown(enable_plugins=False).convert(str(src)).markdown
    images, has_pages = [], False
    if ext == ".docx":
        media = docx_media_in_order(src)
    elif ext == ".pptx":
        media = [(f"pic{i+1}.{e}", b) for i, (e, b) in enumerate(pptx_pictures_in_order(src))]
        md = slide_markers_to_pages(md); has_pages = "<!-- page: " in md
    else:
        media = []
    names = []
    for i, (name, blob) in enumerate(media):
        p = out / "images" / f"img_{i+1}{Path(name).suffix.lower() or '.png'}"; p.write_bytes(blob); images.append(str(p)); names.append(f"images/{p.name}")
    md = replace_nth_images(md, names)
    md_path = out / "out.md"; md_path.write_text(md, encoding="utf-8")
    _proto.progress(1, 1)
    return {"markdown_path": str(md_path), "images": images, "has_page_markers": has_pages, "page_count": None,
            "first_table": None, "last_table": None}

if __name__ == "__main__":
    _proto.serve(handle)
```

```python
from __future__ import annotations
import re, sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent))
import _proto

_converter_cache = {}

def build_converter(opts):
    from docling.document_converter import DocumentConverter, PdfFormatOption, ImageFormatOption
    from docling.datamodel.base_models import InputFormat
    from docling.datamodel.pipeline_options import PdfPipelineOptions, EasyOcrOptions, AcceleratorOptions
    from docling.datamodel.settings import settings
    import os
    models = Path(os.environ["AIDOC_MODELS_DIR"]) / "docling"
    if opts.get("ocr") == "rapidocr":
        from docling.datamodel.pipeline_options import RapidOcrOptions
        ocr = RapidOcrOptions(lang=["chinese_cht"] if "ch_tra" in opts["lang"] else ["en"])
    else:
        ocr = EasyOcrOptions(lang=list(opts["lang"]))
    if opts.get("full_page_ocr"):
        try:
            from docling.datamodel.pipeline_options import OcrMode      # location verified in spike
            ocr.mode = OcrMode.FULL_PAGE
        except ImportError:
            ocr.force_full_page_ocr = True
    po = PdfPipelineOptions(artifacts_path=str(models), do_ocr=True, ocr_options=ocr, do_table_structure=True,
                            generate_picture_images=True, images_scale=2.0,
                            do_formula_enrichment=bool(opts.get("formula")),
                            accelerator_options=AcceleratorOptions(device="cuda"))
    settings.perf.page_batch_size = int(opts.get("page_batch_size", 16))
    return DocumentConverter(format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=po),
                                             InputFormat.IMAGE: ImageFormatOption(pipeline_options=po)})

def table_edges(doc):
    """Return (first, last) TableEdge dicts using prov bbox; None when no tables / no bbox."""
    tables = [t for t in doc.tables if t.prov]
    if not tables: return None, None
    def edge(t, top):
        prov = t.prov[0]; page = doc.pages[prov.page_no]; h = page.size.height
        bb = prov.bbox.to_top_left_origin(h) if hasattr(prov.bbox, "to_top_left_origin") else prov.bbox
        touches = (bb.t <= 0.05 * h) if top else (bb.b >= 0.95 * h)
        return {"page": prov.page_no, "n_cols": t.data.num_cols, "touches_edge": bool(touches)}
    return edge(tables[0], True), edge(tables[-1], False)

def handle(req):
    opts = req["engine_opts"]
    key = (opts.get("ocr"), tuple(opts["lang"]), bool(opts.get("full_page_ocr")), int(opts.get("page_batch_size", 16)), bool(opts.get("formula")))
    conv = _converter_cache.get(key) or _converter_cache.setdefault(key, build_converter(opts))
    out = Path(req["out_dir"]); (out / "images").mkdir(parents=True, exist_ok=True)
    doc = conv.convert(req["src"]).document
    n = doc.num_pages() if callable(getattr(doc, "num_pages", None)) else len(doc.pages)
    parts, images = [], []
    for p in range(1, n + 1):
        md = doc.export_to_markdown(page_no=p)
        pics = [pic for pic in doc.pictures if pic.prov and pic.prov[0].page_no == p]
        links = []
        for k, pic in enumerate(pics, 1):
            img = pic.get_image(doc)
            if img is None: continue
            f = out / "images" / f"page_{p}_{k}.png"; img.save(f); images.append(str(f)); links.append(f"images/{f.name}")
        md = _replace_placeholders(md, links)
        parts.append(f"<!-- page: {p} -->\n{md.strip()}\n")
        _proto.progress(p, n)
    first, last = table_edges(doc)
    md_path = out / "out.md"; md_path.write_text("\n".join(parts), encoding="utf-8")
    return {"markdown_path": str(md_path), "images": images, "has_page_markers": True, "page_count": n,
            "first_table": first, "last_table": last}

def _replace_placeholders(md, links):
    it = iter(links)
    def sub(m):
        try: return f"![]({next(it)})"
        except StopIteration: return ""
    return re.sub(r"<!-- image -->", sub, md)

if __name__ == "__main__":
    _proto.serve(handle)
```

```python
# src/aidoc/engines/runner/mineru_runner.py  (stdlib + mineru only)
from __future__ import annotations
import json, os, re, sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent))
import _proto

def _probe_text(item):
    t = item.get("type")
    if t in ("text", "title", "equation") and item.get("text"): return item["text"].strip()[:40]
    if t == "image" and item.get("img_path"): return os.path.basename(item["img_path"])
    if t == "table": return "<table"
    return None

def insert_page_markers(md, items):
    cursor = 0; out = []; last_page = None; pos_by_page = {}
    for it in items:
        page = it.get("page_idx")
        if page is None or page == last_page: continue
        needle = _probe_text(it)
        if not needle: continue
        pos = md.find(needle, cursor)
        if pos < 0: return None
        line_start = md.rfind("\n", 0, pos) + 1
        pos_by_page[page] = line_start; cursor = pos + len(needle); last_page = page
    if not pos_by_page: return None
    cuts = sorted(pos_by_page.items(), key=lambda kv: kv[1])
    prev = 0
    for page, at in cuts:
        out.append(md[prev:at]); out.append(f"<!-- page: {page + 1} -->\n"); prev = at
    out.append(md[prev:])
    return "".join(out)

def table_edges(middle):
    try:
        pages = middle["pages"] if isinstance(middle, dict) else middle
        tabs = []
        for pg in pages:
            h = pg.get("page_size", [0, 0])[1]
            for blk in pg.get("para_blocks", []):
                if blk.get("type") == "table" and blk.get("bbox") and h:
                    x0, y0, x1, y1 = blk["bbox"]
                    ncols = len(re.findall(r"<t[dh]", (blk.get("html") or ""))) // max(1, (blk.get("html") or "").count("<tr")) if blk.get("html") else 0
                    tabs.append({"page": pg["page_idx"] + 1, "top": y0 / h, "bottom": y1 / h, "n_cols": ncols})
        if not tabs: return None, None
        f, l = tabs[0], tabs[-1]
        return ({"page": f["page"], "n_cols": f["n_cols"], "touches_edge": f["top"] <= 0.05},
                {"page": l["page"], "n_cols": l["n_cols"], "touches_edge": l["bottom"] >= 0.95})
    except Exception:  # structure differs -> no edge info
        return None, None

def handle(req):
    from mineru.parser import parse            # signature verified in Spike C
    out = Path(req["out_dir"]); out.mkdir(parents=True, exist_ok=True)
    tier = req["engine_opts"].get("tier", "basic")
    result = parse(req["src"], tier=tier, ocr_mode="auto", page_range="")
    result.save(str(out))                       # ADAPT per Spike C: pass the writer/dir the API expects
    md_file = next(out.rglob("markdown.md")); base = md_file.parent
    md = md_file.read_text(encoding="utf-8")
    items = json.loads((base / "structured_content.json").read_text(encoding="utf-8"))
    if isinstance(items, dict) and "pages" in items:            # content list V2 grouped per page
        items = [dict(i, page_idx=p.get("page_idx", k)) for k, p in enumerate(items["pages"]) for i in p.get("items", p.get("content", []))]
    marked = insert_page_markers(md, items)
    has_pages = marked is not None
    md = marked or md
    images = [str(p) for p in sorted((base / "images").glob("*")) if p.is_file()]
    middle = json.loads((base / "middle_json.json").read_text(encoding="utf-8")) if (base / "middle_json.json").exists() else {}
    first, last = table_edges(middle)
    total = len({i.get("page_idx") for i in items}) or None
    (out / "out.md").write_text(md, encoding="utf-8")
    _proto.progress(total or 1, total or 1)
    return {"markdown_path": str(out / "out.md"), "images": images, "has_page_markers": has_pages, "page_count": total,
            "first_table": first, "last_table": last}

if __name__ == "__main__":
    _proto.serve(handle)
```

2. `probing`: `probe_file(source_path)`; `probe.error` → `failed(input: corrupt|encrypted)`. Cache: `lookup_cached(store, sha, output_dir)` and not `force` and (level ok or not `retry_low`) → `skipped`.

5. 6. All tried: `best` present → write with `quality.level="low"` → status `low`; else `failed(engine: all engines failed)`.
7. Write: `OutputWriter.write(norm.markdown, norm.assets, sidecar)`, `finalize(output_dir)` (`FsBusyError` → `failed(transient)`), `store.upsert_document(status=q.level, work_copy_path=..., work_copy_expires_at=now+retention)`, `update_task(status, quality_json, output_dir)`; segment row → `done`.

```python
from pathlib import Path
import pytest
from aidoc.config import load_config
from aidoc.engines.registry import get_engines
from aidoc.models import ConvertOptions, TaskStatus
from aidoc.names import file_sha256
from aidoc.pipeline import run_task
from aidoc.store import Store
from tests.fakes.scenario import write_scenario, fake_env

@pytest.fixture
def env(tmp_root, monkeypatch, fixtures):
    sc = write_scenario(tmp_root / "sc.json"); fake_env(monkeypatch, sc)
    cfg = load_config(); store = Store(tmp_root / "data" / "aidoc.db")
    def make_task(name, out_name=None, **opt):
        src = tmp_root / (out_name or name); shutil.copy(fixtures / name, src)
        opts = ConvertOptions(output_dir=tmp_root / "out", **opt)
        job = store.create_job(opts, "cli")
        tid, _ = store.create_task(job, str(src), file_sha256(src), src.stat().st_size, src.stat().st_mtime, opts.lang,
                                   str(tmp_root / "out" / Path(src).stem))
        return tid
    return dict(cfg=cfg, store=store, sc=sc, make=make_task, root=tmp_root)

def test_happy_path_docling(env):
    tid = env["make"]("text.pdf"); events = []
    st = run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"], emit=lambda k, p: events.append(k))
    assert st == TaskStatus.done
    t = env["store"].get_task(tid); assert t["engine"] == "docling" and t["quality"]["level"] == "ok"
    out = env["root"] / "out" / "text"
    assert (out / "text.md").exists() and (out / "assets" / "p1_1.png").exists()
    sc = json.loads((out / "text.json").read_text(encoding="utf-8"))
    assert sc["engine"] == "docling" and sc["tried"][0]["engine"] == "docling" and sc["pages"] == 3 and sc["segments"] == 1
    assert env["store"].find_document(t["sha256"], str(out))["status"] == "ok"
    assert "task.updated" in events and not (env["root"] / "out" / ".tmp" / tid).exists()

def test_fallback_on_low_quality(env):
    write_scenario(env["sc"], rules=[{"match": {"engine": "docling"}, "behavior": "low"}])
    tid = env["make"]("text.pdf")
    assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done
    t = env["store"].get_task(tid)
    assert t["engine"] == "mineru" and [a["engine"] for a in t["tried"]] == ["docling", "mineru"] and t["tried"][0]["score"] < 0.5

def test_all_low_keeps_best(env):
    write_scenario(env["sc"], default="low")
    tid = env["make"]("text.pdf")
    assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.low
    assert env["store"].get_task(tid)["quality"]["level"] == "low" and (env["root"] / "out" / "text" / "text.md").exists()

def test_engine_error_then_fallback(env):
    write_scenario(env["sc"], rules=[{"match": {"engine": "docling"}, "behavior": "error"}])
    tid = env["make"]("text.pdf")
    assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done
    assert env["store"].get_task(tid)["tried"][0]["error_kind"] == "engine"

def test_input_errors(env):
    for name, code in [("encrypted.pdf", "encrypted"), ("corrupt.pdf", "corrupt"), ("bad.exe", "unsupported_type")]:
        tid = env["make"](name)
        assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.failed
        t = env["store"].get_task(tid); assert t["error_kind"] == "input" and code in t["error_msg"]

def test_forced_unsupported(env):
    tid = env["make"]("sample.docx", engine="mineru")
    assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.failed
    assert "engine_unsupported" in env["store"].get_task(tid)["error_msg"]

def test_cache_skip_and_force_and_retry_low(env):
    tid = env["make"]("text.pdf"); run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"])
    tid2 = env["make"]("text.pdf")
    assert run_task(env["store"], tid2, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.skipped
    tid3 = env["make"]("text.pdf", force=True)
    assert run_task(env["store"], tid3, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done
    write_scenario(env["sc"], default="low"); tid4 = env["make"]("sample.docx")
    assert run_task(env["store"], tid4, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.low
    tid5 = env["make"]("sample.docx"); assert run_task(env["store"], tid5, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.skipped
    write_scenario(env["sc"]); tid6 = env["make"]("sample.docx", retry_low=True)
    assert run_task(env["store"], tid6, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done

def test_cjk_paths(env, fixtures):
    tid = env["make"]("text.pdf", out_name="測試 報告.pdf")
    assert run_task(env["store"], tid, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done
    assert (env["root"] / "out" / "測試 報告" / "測試 報告.md").exists()

def test_same_stem_different_content(env):
    t1 = env["make"]("text.pdf", out_name="report.pdf"); t2 = env["make"]("sample.docx", out_name="report.docx")
    for t in (t1, t2): assert run_task(env["store"], t, get_engines(env["cfg"]), env["cfg"]) == TaskStatus.done
    dirs = sorted(p.name for p in (env["root"] / "out").iterdir() if p.name.startswith("report"))
    assert len(dirs) == 2 and dirs[0] == "report"

def test_no_engine_available(env, monkeypatch):
    engines = get_engines(env["cfg"])
    for e in engines.values(): monkeypatch.setattr(e, "available", lambda: False)
    tid = env["make"]("text.pdf")
    assert run_task(env["store"], tid, engines, env["cfg"]) == TaskStatus.failed
    assert "aidoc setup" in env["store"].get_task(tid)["error_msg"]
```

```python
    d = tmp_root / "in"; (d / "sub").mkdir(parents=True); (d / ".hidden").mkdir()
```

## Implementation notes / deviations

Recorded while executing P1 on 2026-09-24 (Windows 11, RTX 5070 Ti sm_120, driver 591.86). Installed:
markitdown 0.1.8; docling 2.130.0 + torch 2.11.0+cu128 + onnxruntime-gpu 1.25.1; mineru 4.0.7 + torch 2.11.0+cu128.

**Spike decisions** (`docs/superpowers/spikes/`)
- A (Docling per-page export): no duplication and no loss (text.pdf 11 = 11 lines, big.pdf 90 = 90) → index A2 kept.
- B (§13.5 OCR): RapidOCR recall 1.000 vs EasyOCR 0.918–0.975 on the scanned fixtures → **`docling_ocr = "rapidocr"`**
  is the default (`aidoc.toml`, `Engines`, `ConvertOptions`); `docling[rapidocr]` + `onnxruntime-gpu` are main env deps.
  EasyOCR did use the GPU. Both OCR model sets are downloaded by `aidoc setup docling`.
- C (§13.1 MinerU): API recorded; `standard` runs on the GPU (llama.cpp **Vulkan** build, no ggml-cuda), 1.7–2.4× basic
  per page, recall only 0.995 → 1.000 on one fixture → not 「明顯較好」, **tier stays `basic`**.

**Environment / packaging**
- `markitdown[all]==0.1.8` is unresolvable (needs pre-release `azure-ai-contentunderstanding`); env lists the local extras
  `docx,pptx,xlsx,xls,pdf,outlook,audio-transcription`.
- Docling env: `override-dependencies` drops the CPU `onnxruntime` (it shadowed `onnxruntime-gpu`, forcing RapidOCR onto
  CPU); `onnxruntime-gpu>=1.23,<1.26` because 1.26+ wheels target CUDA 13 while torch is cu128.
- MinerU download adds `--small-backend torch`; docling download uses `docling-tools.exe` and fetches easyocr + rapidocr
  (`--rapidocr-backend-lang onnxruntime:chinese_cht` / `onnxruntime:en`).
- New env overrides `AIDOC_ENVS`, `AIDOC_MODELS` + `tests/integration/conftest.py`: slow tests keep DB/output in a tmp root
  but use the real envs and models (the planned `tmp_root` made every real engine unavailable).
- `.gitattributes` marks fixtures binary (core.autocrlf=true on the host).

**Behaviour added / adapted**

  unreadable input to `RunnerError(input)`; docling uses `raises_on_error=False`.
- MinerU runner follows the real 4.0.7 shapes (`pages[].blocks[]`, `content`, `image_source`, normalised bboxes,
  `table_body` HTML), reports only images referenced by the markdown, and places page markers by walking every item of a
  page (a 40-char prefix re-matched inside repeated content put both markers at the top — found in acceptance).
- Page markers are emitted only for PDF input (MinerU/Docling added `<!-- page: 1 -->` to images; e2e expects none).
- `DoclingEngine.engine_opts` turns on FULL_PAGE OCR for scanned probes (image, text_ratio < 0.5, image_cover > 0.6).
- Output files are named after the output dir (`out/report-<sha8>/report-<sha8>.md`); `assets/` always exists.
- CLI: stdout/stderr reconfigured (UTF-8 when redirected, `errors=replace` on a cp950 console — real `aidoc setup mineru`
  crashed); output dir printed relative to cwd when inside it; `batch` prints the manifest and a summary.
- Batch: manifest `source` is relative to the input dir (basename when unknown); `-o` inside the input dir is excluded.

**Final whole-branch review (fresh reviewer) — fixed**

- Non-`EngineError` exceptions left tasks stuck in `checking` with a traceback → `run_task` ends them as
